50+Money School 受講規約

2026年11月版（2026年11月18日から）

株式会社シャガ（以下「当社」といいます。）が運営する講座「50+Money School」（以下「本スクール」といいます。）の受講に関する規約です。

第1条（本規約の適用と契約の成立）

  1. 本規約は、本スクールに申し込む方および本スクールを受講する方（以下「受講者」といいます。）と当社との間の受講に関する契約（以下「本契約」といいます。）の内容として適用されます。受講者には、3ヶ月の実践講座の期間中の方だけでなく、その後の9ヶ月のMembershipの期間中の方も含まれます。
  2. 本スクールの各期の募集内容は、その期の募集要項（以下「募集要項」といいます。）に定めます。募集要項は、本規約と一体のものです。本規約、お申し込みをされた期の募集要項、お申し込みの最終画面に表示される内容が、本契約の内容となります。
  3. 募集要項に、その期だけに適用される条件がある場合は、その条件に従います。
  4. お申し込み後に次の期の募集要項が公表された場合も、その受講者には、お申し込みをされた期の募集要項が引き続き適用されます。
  5. 本契約は、当社がお申し込みを受け付け、受講料（分割払いの場合は1回目）の入金を確認した時に成立します。クレジットカードの場合は、決済の完了を入金として扱います。
  6. 当社は、本契約の成立後、メールで受講のご案内をお送りします。
  7. 本規約は、スマートフォンアプリ「50+Money」（以下「本アプリ」といいます。）の利用規約に定める「お申し込み時の条件」にあたります。本アプリの利用規約と本規約の内容が異なる場合、本アプリの利用については本アプリの利用規約が、お申し込みに関する契約（内容、料金、返金など）については本規約が優先されます。

第2条（受講資格）

  1. 本スクールを受講できるのは、次の条件をすべて満たす個人の方です。
    • 18歳以上の方
    • 本規約とプライバシーポリシーに同意した方
  2. 受講できるのは、お申し込みをされたご本人に限ります。本アプリのアカウント、Zoomの参加情報（URL、ID、パスコードなど）、教材を、他の方に渡したり、貸したりしないでください。
  3. 次のいずれかに該当する場合は、お申し込みをお断りすることがあります。
    • 事業として、または事業のために受講しようとする場合（お勤めの方や自営業の方が、ご自身の生活とお金のために受講することは、これにあたりません。）
    • 本スクールの内容を、ご自身の仕事の教材として使う目的で受講しようとする場合
    • お申し込みの内容にうそがある場合
    • 第22条に定める反社会的勢力に該当する場合
    • 過去に本規約に違反し、本契約を解除されたことがある場合

第3条（本スクールの内容）

  1. 本スクールは、3ヶ月間の実践講座（全6回）を中心とするライフ＆マネープランニング講座です。
  2. 受講者には、実践講座の終了後、9ヶ月間のMembershipを追加料金なしで提供します。
  3. 実践講座とMembershipを合わせた初年度のサービス提供期間は12ヶ月間です。
  4. 具体的な提供内容、日程、サポート内容等は募集要項に定めます。

第4条（受講料と支払い）

  1. 本スクールの受講料は、募集要項に定めます。
  2. 受講料には、3ヶ月間の実践講座と、実践講座終了後9ヶ月間のMembershipが含まれます。Membershipについて、初年度の追加料金は発生しません。
  3. 2年目以降のMembershipの継続は任意とし、継続する場合は別途お申し込みが必要です。自動更新は行いません。
  4. お支払い方法、時期、および受講者の負担となる費用は募集要項のとおりとします。

第5条（分割払い）

  1. 分割払いを選べるのは、銀行振込の場合で、お申し込み時に限ります。
  2. 分割払いの手数料はかかりません。お支払い総額は、一括払いと同じです。
  3. 分割払いは、受講料のお支払い方法です。3ヶ月の講座が終了した後も、本契約で定められた残りのお支払いは続きます。
  4. 分割払いのお支払いが遅れた場合、当社は、20日以上の期間を定めて、メールでお支払いを求めます。その期間内にお支払いがない場合は、残りの支払い額を一括で請求するか、本契約を解除することができます。この手続きを行う前に、一括請求や解除は行いません。
  5. お支払いが遅れた金額には、法定利率による遅延損害金がかかります。
  6. 分割払いの受講料について本契約が解除された場合、当社が請求できる金額は、法令に定められた上限までとします。

第6条（開講前のキャンセルと返金）

  1. お申し込みの日から8日以内（お申し込みの日を1日目として数えます。）に、メールまたはLINEで当社にお申し出いただいた場合、受講者は理由を問わず本契約を解除できます。この場合、当社はお支払い済みの受講料を全額返金します。
  2. お申し込みの日から9日目以降、第1回の開講日の前日までに、メールまたはLINEで当社にお申し出いただいた場合（第1回の開講日の前日中に届いたお申し出を含みます。）、受講者は本契約を解除できます。この場合、当社はお支払い済みの受講料から、募集要項に定めるキャンセル手数料を差し引いた金額を返金します。
  3. 分割払いの場合、まだお支払いいただいていない分については、お支払いの必要はありません。
  4. お申し出の際は、お申し込み時に登録されたお名前とメールアドレスを添えて、次のいずれかへご連絡ください。
    • メール：contact@50plusmoney.com
    • LINE公式アカウント「50+Money School事務局」（https://line.me/R/ti/p/%40381aptxw）
  5. 返金は、お申し出を受け付けた後、遅滞なく行います。銀行振込の場合は、受講者が指定する口座へ振り込みます。クレジットカードの場合は、決済の取り消しまたは返金の方法で行います。
  6. 返金時の振込手数料は、当社が負担します。銀行振込でお支払いいただいた際に、受講者が負担した振込手数料は返金しません。

第7条（開講後の解除と返金）

  1. 第1回の開講日以降に、受講者のご都合で本契約を解除する場合、お支払い済みの受講料は返金しません。
  2. 返金を行わないのは、開講にあわせて、受講者お一人おひとりの席、教材、アプリ、講師の体制を用意するためです。
  3. 銀行振込の分割払いを選んだ方は、本契約の解除後も、第5条第6項の上限の範囲で、残りのお支払いが続きます。
  4. 病気などのやむを得ない事情がある場合は、お問い合わせください。事情に応じて個別にご相談をお受けします。ただし、返金や変更をお約束するものではありません。
  5. 当社の都合で講座を続けられなくなった場合の返金は、第9条のとおりです。
  6. 本規約は、法令によって受講者に認められている解除や取り消しの権利を制限しません。

第8条（8日以内の解除と、クーリング・オフについて）

  1. お申し込みの日から8日以内は、第6条第1項のとおり、理由を問わず本契約を解除でき、当社はお支払い済みの受講料を全額返金します。
  2. 法令により、クーリング・オフその他の解除や取消しが認められる場合は、その法令の定めが本規約に優先します。

第9条（当社による変更・中止）

  1. 当社は、やむを得ない場合に、講座の日程、時間、講師、形式（会場からZoomへの変更など）、内容の一部を変更することがあります。変更する場合は、事前にお知らせします。
  2. 変更した回に出られない場合は、アーカイブでご覧いただけます。
  3. 当社の都合、または天災などのやむを得ない事情により開講できない場合は、お支払い済みの受講料を全額返金します。返金時の振込手数料は、当社が負担します。
  4. 開講後に、当社の都合、または天災などのやむを得ない事情により講座を続けられなくなった場合は、まだ提供していない分に応じて、お支払い済みの受講料を返金します。
  5. 当社が本アプリの提供を終了することで、初年度の会員期間中に、受講者が本アプリを使えなくなる場合は、当社は代わりの方法を提供するか、まだ提供していない分に応じて、お支払い済みの受講料を返金します。
  6. 天災、停電、通信回線やZoomなどの外部サービスの障害により、講座を一時的に予定どおり行えない場合は、日程や形式を変更するか、録画を提供するなどして対応します。

第10条（欠席とアーカイブ）

  1. 欠席した回については、受講料の返金や、別の日への振替はありません。
  2. 欠席した回は、アーカイブ（録画）で受講できます。アーカイブを視聴できる期間は、初年度の会員期間中です。
  3. 会場で開催する回について、会場に来られない場合は、Zoomで受講できます。この場合、欠席にはなりません。

第11条（講座の録画）

  1. 当社は、講座を録画し、同じ期の受講者にアーカイブとして配信します。
  2. 録画には、受講者の名前、顔、声、発言が含まれることがあります。Zoomの表示名やカメラの設定は、受講者ご自身で変更できます。
  3. 受講者がご自身で講座を録画・録音したり、画面を撮影したりして、その内容を外部に出すこと（公開、共有、投稿を含みます。）は禁止します。

第12条（教材などに関する権利）

  1. 教材、ワーク教材、動画、アーカイブに関する権利は、当社または講師に帰属します。
  2. 受講者は、これらを受講者ご本人の学習のためにのみ使用できます。
  3. 受講者は、これらを複製、転載、再配布、販売したり、他の方に共有したりすることはできません。

第13条（禁止事項）

受講者は、次の行為をしてはいけません。

  • 他の受講者への勧誘や営業、宗教や政治への誘い、金融商品や保険の販売への誘いを行う行為
  • 他の受講者の情報（氏名、発言、資産、家庭の事情など）を外部に出す行為
  • 講師や他の受講者に迷惑をかける行為（中傷、嫌がらせ、講座の進行を妨げる行為を含みます。）
  • お申し込みの際に、うその内容を書く行為
  • 本アプリのアカウント、Zoomの参加情報、教材を、他の方に渡したり、貸したりする行為
  • 第11条第3項、第12条第3項に違反する行為
  • 法令や公序良俗に違反する行為
  • その他、上記に準ずる行為で、講師や他の受講者、当社に重大な迷惑を及ぼす行為

第14条（受講の停止と契約の解除）

  1. 受講者が第13条に違反した場合、当社は理由をお伝えし、違反を改めるよう求めます。
  2. 違反を改めていただけない場合や、違反が重大な場合は、受講を停止するか、本契約を解除することがあります。この場合は、できる限り事前に理由をお知らせします。ただし、他の受講者を保護するために緊急の対応が必要な場合は、事後にお知らせすることがあります。
  3. 当社が本契約を解除した場合は、まだ提供していない分に応じて、お支払い済みの受講料を返金します。ただし、違反が重大で、当社や他の受講者に大きな損害を与えた場合など、違反の内容や程度によっては、返金しないことがあります。
  4. 受講の停止や解除について心当たりがない場合は、下記の問い合わせ先へご連絡ください。当社で状況を確認し、回答します。
